## 세부 체크리스트

- Core: schema/type/size, deny precedence, deterministic digest, canonical cwd/path.
- FS: descriptor 기반 접근, 원래/해결 경로 모두 검사, 신뢰 파일 보호, 단일 삭제.
- Shell: shell=False, absolute executable, exact profile, sanitized env,
  timeout/output bound, network/외부 파일/secret/state 격리.
- Git: verb별 좁은 schema, 옵션 주입 차단, hooks/config 제거,
  push URL/ref와 branch/HEAD 승인 binding, protected/force 차단.
- Approval: 외부 store, operator만 grant, 원자적 일회 소비, 재정규화.
- Audit: 실행 전에 내구 저장, result 연결, 파일 내용 미기록, token redaction.
- Integration: Agent에는 submit만 노출, approve는 operator CLI.
- X: 임시 repo에서 실제 파일 생성부터 commit까지 Gateway 사용.
  remote는 임시 local bare repo. 사용자 원본 Git에 commit/push하지 않는다.

## 테스트 순서

expected behavior → 실패 regression → 구현 → focused → integration/adversarial
→ full suite → exec 기록. 새 변경·실패가 없으면 무의미하게 suite를 반복하지 않는다.

## 범위와 완료

외부 API/모델/cloud/browser/multi-agent/범용 shell parser는 제외한다.
MCP는 외부 proxy가 아닌 로컬 coding-agent 도구 연결이다.
Level 2 구현과 제한된 X workload의 Level 3 합격을 구분한다.
호스트 직접 도구 우회 및 1~2주 실사용 미검증은 명시한다.
