# 002 Live Host and Continued Dogfooding

Status: 2026-10-04, 002-01~09 완료. 002-10은 관찰 준비 완료/장기 사용 미측정.
사용자가 002 세분화·실행을 요청했다. Guard는 로컬 프로그램으로 유지한다.

001의 정해진 X 요청 재생과 구분하여, 설치된 Codex CLI를 테스트 대상으로 실행한다.
사용자 전역 설정을 변경하지 않고 별도 fixture, 정책, 상태, 세션 로그를 보존한다.
위험 테스트는 가짜 데이터와 임시 저장소만 사용한다.

기존 대규모 프로젝트·다른 host·장기 사용까지 일반화하지 않는다.

## 측정

- 정상 작업: 변경 파일, 빌드/테스트 성공, commit 여부, Guard 제안·허용·거부·승인 수.
- 마찰: 안전한 정상 요청이 거부되거나 정책 등록이 필요한 횟수, 재시도 원인, 대기 시간.
- 경계: agent가 정책/상태/Guard를 수정하거나 직접 도구로 우회할 수 있는지.
- 장애: hook 실행 실패나 MCP 중단 시 효과가 발생하는지. 성공한 보호와 미보호 경로를 구분.
- 종료 질문은 현재 환경·허용 profile에서 판정한다. 몇 번의 자동 실행을 장기 사용으로 환산하지 않는다.
