# 001-05 — Git Adapter

Date: 2026-10-03. Base commit: b93ba56. Policy: 001.

## Implementation

status/diff/log, explicit add, commit, feature branch 생성, exact push를 구현했다.
verb별 schema로 옵션 주입을 막고 unknown/reset/clean, add dot, force/protected push를 거부한다.
local/global executable config, aliases, attributes, hooks, fsmonitor, pager, GPG를 제어한다.
Git child는 .git만 쓰며 push 때 승인된 remote scope를 추가한다.

## Tests

`test_shell_git.py`: 17 tests, 최종 전체 회귀 모두 pass.
GT-01~05, 실제 temp commit/history, untrusted pre-commit hook 미실행,
민감 tracked file, unsafe config, bare remote push 포함.

## Observed / Decisions

중복 [core] config가 파싱 예외로 빠져나갔다. configparser 오류를 GT-CONFIG DENY로 바꿨다.
`/var`와 `/private/var`의 같은 remote가 서로 다르게 판정돼 정상 push가 막혔다.
trusted profile과 요청 remote를 canonicalize하고 원래 URL도 action binding에 유지했다.

## Limits

linked worktree, hooks/filters/attributes가 필요한 저장소는 이 profile에서 거부한다.
SSH와 credential URL은 지원하지 않는다. HTTPS service push는 검증하지 않았으며,
실제 remote mutation 검증은 임시 local bare repository에서만 수행했다.
사용자 원본 repository에 commit/push하지 않았다.
