# 002-10 — 지속 사용 관찰

Status: 관찰 준비 완료, 1~2주 누적 사용과 실제 사용자 평가는 미측정.

2026-10-03~04의 모델 task와 재검증을 수행했다. 날짜가 하루 바뀌었다는 사실을
1~2주 실사용 증거로 환산하지 않는다. 이 항목은 현재 자동 실행을 더 반복해 충족할 수 없다.

다음 관찰에서 task마다 남길 항목:

| 항목 | 기록 |
|---|---|
| 저장소와 작업 | 실제 언어, bug/refactor/test/config 목표 |
| 정상 개발 차단 | command/path, rule, 정상 작업이었던 근거 |
| profile 수정 | 운영자가 추가한 capability, 준비/수정 시간 |
| 승인 피로 | publish 승인 수, 같은 동작의 반복 문의 여부 |
| 복구 | 차단 뒤 정상 대안으로 task를 마쳤는지 |
| 사용자 의견 | 계속 켜둘지, 가장 답답했던 구체적 작업 |

재현 launcher와 fixture 준비는 [Local Usage](../10-local-usage.md)에 있다.
실제 사용자에게 전체 완료를 승인받았거나 장기 사용 인터뷰를 했다고 기록하지 않는다.
현재 가상 X 판정과 한계는 [002-09](002-09-verdict.md)에 완료했다.

2026-10-04 [003](003-real-project-usability.md)에서 기존 저장소 두 개의 여섯 task를
이어 실행하고 profile/탐색/선택 테스트 마찰을 보완했다. 이 결과는 추가 자동 실험이며,
이 항목의 실제 사용자·장기 관찰 완료로 계산하지 않는다.
