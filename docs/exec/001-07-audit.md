# 001-07 — Durable Audit and Redaction

Date: 2026-10-03. Base commit: b93ba56. Policy: 001.

## Implementation

실행 전에 decision을 JSONL로 append/fsync한다. 승인 pending과 execution result는
parent event id로 연결한다. audit 실패 전에는 action을 실행하지 않는다.
partial write를 완전히 기록하고 ordinary single-link file만 허용한다.
내용과 stdin을 생략하며 stdout/stderr는 audit에 남기지 않는다. 반환 결과는 token 형태를 redaction한다.

## Tests

AU-01/02, fake token의 content/result redaction, audit outage 시 실제 write 없음,
정상 decision/result link 검증. 최종 전체 suite 67 pass.

## Observed / Decisions

파일 내용을 모두 기록하는 대신 action metadata와 decision/rule/result를 남겨 정보 노출을 줄였다.
실행 후 result audit만 실패한 경우 executed 상태를 숨기지 않고 audit_error를 돌려준다.
Git의 trusted read-only state queries는 정규화 내부 작업이며 독립 Agent proposal로 세지 않는다.

redaction은 알려진 token 형태를 대상으로 하며 임의 secret의 완전 탐지나 외부 tamper-proof 저장은 아니다.
