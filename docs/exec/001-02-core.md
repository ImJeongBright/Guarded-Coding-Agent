# 001-02 — Core and Pure Policy

Date: 2026-10-03. Base commit: b93ba56. Policy: 001, uncommitted implementation.

## Implementation

`domain.py`의 strict ToolRequest schema, immutable Action/Verdict, decision enum,
canonical JSON SHA-256 digest와 precedence 함수를 만들었다. 배열은 요청 snapshot으로 복사한다.
`policy.py`는 normalized Action을 I/O 없이 평가한다. explicit DENY > APPROVAL > ALLOW,
unknown은 default DENY이며 Gateway에서 동일 함수를 사용한다.

## Observed / Decisions

먼저 test를 만들어 domain/policy 모듈이 없는 ImportError를 확인한 뒤 구현했다.
Unknown operation, extra field, 잘못된 type, 크기 제한과 인자 digest 변경을 검사했다.
정규화가 실패하면 실행되지 않으며 예상하지 못한 ingress 오류도 구조화된 DENY로 돌려준다.

## Limitations

pure policy는 normalizer의 Action 계약을 전제로 한다. 실제 filesystem/Git 상태 검사는
각 adapter에서 수행한다. 모델 의미 분류나 policy DSL은 도입하지 않았다.
